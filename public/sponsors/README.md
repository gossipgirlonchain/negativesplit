Sponsor logos.

Drop a file in here named by position number, then add the logo line to that
position in lib/sponsor-manifest.ts:

    "01": { brand: "Deepstate", url: "https://deepstate.sh", logo: "/sponsors/01.svg" },

SVG is best. PNG and WebP work. The file is drawn into its plate on the
technical drawing and shown beside the brand in the position list, so
anything with a transparent background reads better than a white box.
